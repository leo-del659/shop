## Design Context

### Users
社区/生活类平台「集邻生活」的后台运营管理员。他们每天需要在这里处理商品审核、订单、商户入驻、供应商、结算等事务，界面需要长时间使用不疲劳，信息层级清晰，操作高效。

### Brand Personality
亲切、可靠、现代、有社区温度。不是冷冰冰的工具，而是让运营人员感到专业且舒适的工作台。

### Aesthetic Direction
- **基调**：温暖明亮的浅色系，以柔和的蓝紫作为品牌色，搭配充足留白与轻阴影，营造干净、可信的氛围。
- **形态**：大圆角卡片、柔和渐变、细腻的 hover 与进入动效，避免锐利边框和强烈对比。
- **字体**：系统字体栈优先，标题适度加粗，正文保持清晰可读。
- **动效**：缓动函数以 ease-out / cubic-bezier 为主，动效服务于状态变化，不喧宾夺主。
- **反参考**：避免纯黑/纯白极端、霓虹高饱和、青+深色科技 cliché、过度毛玻璃与无意义装饰。

### Design Principles
1. **信息先于装饰**：每个视觉元素都服务于功能和信息层级。
2. **一致的节奏**：圆角、间距、阴影、色彩在各个页面保持统一。
3. **温和的反馈**：hover、focus、加载状态使用柔和过渡，不突兀。
4. **可长时间使用**：避免高对比刺眼配色，优先舒适可读。
